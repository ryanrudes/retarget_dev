# Balance Board on Roller
The board contains 4 markers fixed on the board surface, and 2 on the edges of the board. The contact plane
is fit to the 4 markers on the board surface, and the outward direction in the patch local frame is defined as pointing
out of the object. Since the marker centers are slightly above the actual contact surface, we need to apply an inward
offset. This offset is measured to be roughly 4.6 mm inward.

# Left Shoe
The shoe's sole patch was calibrated using an external calibration tool (a flat plane with 3 markers attached). The
calibration tool was placed flush to the bottom of the shoe. The outward direction was defined as pointing out of the shoe,
or into the calibration tool. Since the markers on the calibration tool are slightly above the actual sole's contact surface,
we need to apply an outward offset. This offset is measured to be roughly 3.95 mm outward.
